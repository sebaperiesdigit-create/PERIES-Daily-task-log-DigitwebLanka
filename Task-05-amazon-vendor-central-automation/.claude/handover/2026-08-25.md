# Handover — 2026-08-25

## Scope of the day
Rest of the core pipeline (matching → filling → validation → audit log → report), plus the
Streamlit UI (Day 8), then a first real test run against actual files supplied for the day.

## What was done
- **New app modules**:
  - `app/booking_batch_key.py` — builds/parses `BookingBatchKey`
    (`PO-DESTINATIONFC-YYYYMMDD-SEQUENCE`), with a `TEST_` prefix option for dry runs.
  - `app/job_folders.py` — creates/manages the `jobs/<BookingBatchKey>/01_raw_amazon .. 05_reports`
    folder structure; owns file upload/replace/remove logic used by the UI.
  - `app/asn_info_reader.py` — generic label-scan reader for the `ASN Info` sheet. Added the
    `ASN_INFO_LAYOUT_CONFIRMED` flag (currently `False`) — every value it returns is marked
    `UNVERIFIED` until a real Atisraj-approved sample confirms the sheet's exact cell layout.
  - `app/source_data.py` — normalizes the `02_source_data` CSV/XLSX (PO, EAN, CartonNo,
    QtyInCarton required; SKU, TotalQty, TrackingID, AMZNCC, DestinationFC, DispatchDate
    optional). Added `TotalQty` beyond the guide's exact schema so rule 5 (allocation total vs.
    ship quantity) can actually fail against an independent value.
  - `app/matcher.py` — PO+EAN composite-key matching against Amazon rows, SKU/ASIN as
    cross-checks only; zero/multiple matches flagged, never guessed.
  - `app/filler.py` — writes `QtyInCarton` into the matched Box N Qty cell on a **copy** of the
    raw workbook; supports split quantities across multiple cartons for one product.
  - `app/integrity.py` — post-fill checks that all sheets/formulas/formatting survived.
  - `app/validation.py` — the 12-rule validation gate (PASS/AMBER/FAIL per rule).
  - `app/audit_log.py` — writes the per-run audit JSON (BookingBatchKey, source filenames,
    operator, timestamp, validation result, error count, output filename).
  - `app/report.py` — human-readable validation report.
  - `app/pipeline.py` — wires read → match → fill → validate → audit into one run.
  - `streamlit_app.py` — the UI: create/select a job, upload raw XLSX + source data + packing
    docs, view Summary/Match/Validation tabs, Generate button. Runs on `127.0.0.1:8501` only —
    confirmed not reachable off-box, never talks to Amazon Vendor Central.
- **New tests**: `test_booking_batch_key.py`, `test_job_folders.py`, `test_source_data.py`,
  `test_matcher.py`, `test_filler.py`, `test_validation.py`, `test_audit_log.py`,

## Known limitations flagged at end of day (by design, not oversight)
1. **Generate cannot reach GREEN yet, ever, on this build.** Rules 1, 2 and 8 (carton-total
   cross-check, tracking, destination) are hard RED-blocked because `ASN Info`'s real cell
   layout is still unconfirmed. This unblocks only once a real Atisraj-approved sample lets
   someone flip `ASN_INFO_LAYOUT_CONFIRMED = True` in `app/asn_info_reader.py`.
2. Streamlit's `file_uploader` can't be driven by automated pytest — covered instead by direct
   unit tests of `job_folders.py` plus manual/AppTest verification.
3. Rule 10 (lot/expiry) is always AMBER, never a hard stop — the guide never states which
   products require it; treating it as RED would false-block every booking.
4. `samples/` is still empty — no real Amazon files committed to the repo; the automated test
   suite still runs against synthetic fixtures only. (Real files exist now under `jobs/` and
   `User-Guide/`, but those are job working data, not the curated `samples/` set, and `jobs/*`
   is gitignored.)
